# Dataset

Primary dataset: **CASIA-Iris-Interval** (near-infrared eye images, multiple samples per eye).
Download from the CASIA Biometrics Ideal Test site (registration and a research/education agreement required). The images are not redistributed in this repository.

## Layout

- `raw/` - full dataset, gitignored. Keep the original structure: `raw/CASIA-Iris-Interval/<subject>/L/*.jpg` and `.../R/*.jpg`.
- `samples/` - the ten images used by the tests and the demo. Copy them from your CASIA download (the folder is empty in a fresh clone):

  | Image | Source folder under `raw/CASIA-Iris-Interval/` |
  |---|---|
  | `S1088L01.jpg`, `S1088L02.jpg`, `S1088L03.jpg` | `088/L/` |
  | `S1107L04.jpg` (a hard, occluded case) | `107/L/` |
  | `S1193L01.jpg`, `S1193L02.jpg`, `S1193L03.jpg` | `193/L/` |
  | `S1239R01.jpg`, `S1239R02.jpg`, `S1239R03.jpg` | `239/R/` |

- `debug/`, `cache/` - generated by the scripts, gitignored.

If CASIA access is delayed, MMU-Iris or UBIRIS.v1 can substitute for development of the pipeline; the pipeline is dataset-agnostic as long as images are grayscale NIR eye crops (the tests and the iris-radius prior assume CASIA scale).
